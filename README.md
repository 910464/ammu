# A Little Place for Ammu — Version 2 ❤️

This is a static romantic website built for Ammu.

## Run
Open `index.html` in a browser.

## Personalize
Open `app.js` and change:
- `nextMeeting` to your actual next meeting date/time.
- `missMessages`, `presenceMessages`, `questions`, and `activities`.
- Edit the timeline text in `index.html`.
- Add photos under `assets/`.

## Current features
- Personalized opening screen
- Romantic landing page
- Couple photo
- "I miss you" heart animation
- Rotating love reminders
- Relationship timeline
- Open-When letters
- Memory gallery starter
- Couple questions and activities
- Emergency hug interaction
- Local-only message box
- Comfort/breathing mode
- Meeting countdown
- Secret love note
- Mobile responsive navigation
- Scroll reveal animations

## Important privacy note
The V2 chat and secret note are client-side features. The chat is stored in this browser's localStorage and is NOT a real private messaging system. The "secret" section is also not security. For a genuine private website, V3 should add authentication and a hosted backend/database.
